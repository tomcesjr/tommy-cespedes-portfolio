## 1. Project Overview

This project is a personal portfolio website developed using HTML, CSS, and JavaScript. The purpose is to showcase my educational background, technical skills, programming projects, and professional experiences.

The website is designed to represent me professionally while demonstrating my interest in front-end web development and UI/UX design.

## 2. Target Audience

My target audience includes potential employers, recruiters, internship coordinators, and other professionals interested in reviewing my technical skills and projects.

The website allows visitors to learn about my background, view my work, and find ways to contact me.

## 3. Content Strategy and Information Organization

The website is organized into the following sections:

- **Home:** Introduces me and my career interests.
- **About:** Highlights my background, education, technical skills, and experience.
- **Portfolio:** Displays selected programming and development projects.
- **Contact:** Intended to provide professional contact information and communication options.

Each section is designed to present information clearly and allow visitors to navigate the website easily.

The website follows a clean, professional design with a light background, dark text, and red accent colors.

The design includes a sidebar navigation menu, typography, progress bars, project screenshots, and organized content sections.

CSS Flexbox is used to organize elements into columns and rows.
